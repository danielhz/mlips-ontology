\begin{abstract}
Machine learning interatomic potentials (MLIPs) have transformed atomistic
simulations by enabling near \emph{ab initio} accuracy at a fraction of the
computational cost. The field now encompasses a growing ecosystem of algorithms,
training datasets, hyperparameters, and target materials, yet the metadata
needed to systematically compare, reproduce, and build upon MLIP studies
remains scattered across papers, scripts, and ad-hoc file formats. We present
the \MLIPsOntology{} and the \MLIPsKG{}: an OWL ontology and a SPARQL-queryable
knowledge graph that capture what is relevant to describe in the datasets and
hyperparameters used to train MLIP models. The ontology is organized into three
modules---Algorithm, Training Data, and Benchmark---and is designed in alignment
with existing ontologies in materials science (MDO, CMSO/ASMO, EMMO) and
machine learning (ML-Schema). The knowledge graph, populated in collaboration
with domain experts, covers major MLIP algorithm families, their
hyperparameters, training datasets with DFT provenance, and published
benchmarks. We complement the ontology with SHACL shapes that enforce data
quality constraints and enable form-based data entry. The resources are hosted
on \Concon{}, a collaborative knowledge graph platform, and extended by
\MLIPE{} (Machine Learned Interatomic Potentials Environment), a set of
domain-specific extension modules for \Concon{} that add features for
atomistic simulation research. We also present \SemASE{}, a Python library
that extends the Atomic Simulation Environment (ASE) with RDF serialization,
providing a programmatic bridge for feeding simulation data into the knowledge
graph.

\end{abstract}
