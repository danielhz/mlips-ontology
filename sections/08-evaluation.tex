\section{Evaluation}
\label{sec:evaluation}
%% ====================================================================

We evaluate the resources along the criteria defined by the ISWC Resources
Track.

\subsection{Design and Technical Quality}

\paragraph{Ontology quality.} We evaluate the \MLIPsOntology{} against
established ontology quality criteria:

\begin{itemize}
\item \emph{Competency question coverage.} All eight competency questions
  (CQ1--CQ8) are answerable as SPARQL queries over the ontology.
  %% TODO: include SPARQL query examples for each CQ
\item \emph{Consistency.} The ontology is verified to be consistent using
  standard OWL reasoners (HermiT, Pellet).
\item \emph{Alignment.} We document explicit alignments with MDO, CMSO/ASMO,
  ML-Schema, PROV-O, and QUDT, verified through manual inspection and
  SPARQL-based alignment validation.
\item \emph{Modularity.} The three-module design allows independent reuse:
  the Algorithm module can be used without the Training Data module, and
  vice versa.
\end{itemize}

\paragraph{SHACL shape validation.} The shapes successfully validate the
current knowledge graph content, with a validation report available alongside
the dataset.

\paragraph{\SemASE{} quality.} Round-trip serialization is verified by automated
tests comparing all attributes at full floating-point precision. The dual-backend
SPARQL client is tested against both Pyoxigraph (local) and HTTP endpoints.

\subsection{Reusability}

The ontology is published under CC BY 4.0 with a persistent IRI and versioned
releases. SHACL shapes are distributed alongside the ontology. \SemASE{} is
available on PyPI under MIT license. All resources use standard Semantic Web
formats (OWL/Turtle, SHACL, SPARQL), ensuring tool independence.

\subsection{Adoption and Impact}

The resources are in active use within the META-LEARN project. The knowledge
graph is publicly queryable, and \SemASE{} is available on PyPI. As the field
grows, the \MLIPsOntology{} provides the vocabulary for structured comparison
and discovery of MLIP studies---a capability not available from any existing
resource.
