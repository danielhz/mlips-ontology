\section{Sustainability and Maintenance}
\label{sec:sustainability}
%% ====================================================================

The ontology is developed within the META-LEARN project, funded by the
ERC (Advanced Grant, 5~years). The primary source is hosted on a
public Git forge\footnote{URL to be added before submission. We are
coordinating with the Institute for Materials Science to use one of
its existing public repositories
(GitHub/GitLab/Codeberg).}, with versioned releases deposited in
DaRUS~\cite{darus2024} with persistent DOIs. The University of
Stuttgart's internal Git server is maintained as an institutional
mirror.  By building on OWL, SHACL, and standard Semantic Web
formats, the ontology is independent of any specific software
implementation.

We plan to engage the MLIP community through workshops and integration with
existing materials science data repositories (NOMAD, Materials Cloud), and
to contribute to Wikidata's coverage of MLIP algorithms and benchmarks.
